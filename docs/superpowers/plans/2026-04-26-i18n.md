# HandType i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract all hardcoded UI strings into Android string resources and provide full translations for the top 10 Google Play Store languages.

**Architecture:** Standard Android string resources (`res/values*/strings.xml`) referenced via `stringResource()` in Compose and `context.getString()` in non-composable callbacks. Android 13+ per-app language support via `res/xml/locale_config.xml` declared in the manifest.

**Tech Stack:** Kotlin, Jetpack Compose, Android string resources (no new dependencies)

## Task 2: locale_config.xml + Android 13 per-app language support

**Files:**
- Create: `app/src/main/res/xml/locale_config.xml`
- Modify: `app/src/main/AndroidManifest.xml` — add `android:localeConfig` to `<application>`

- [ ] **Step 1: Create locale_config.xml**

Create `app/src/main/res/xml/locale_config.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<locale-config xmlns:android="http://schemas.android.com/apk/res/android">
    <locale android:name="en"/>
    <locale android:name="es"/>
    <locale android:name="pt-BR"/>
    <locale android:name="ru"/>
    <locale android:name="ja"/>
    <locale android:name="hi"/>
    <locale android:name="de"/>
    <locale android:name="fr"/>
    <locale android:name="ko"/>
    <locale android:name="zh-Hans"/>
</locale-config>
```

- [ ] **Step 2: Add localeConfig to manifest**

In `app/src/main/AndroidManifest.xml`, add `android:localeConfig="@xml/locale_config"` to the `<application>` element. The element should look like:

```xml
    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:localeConfig="@xml/locale_config"
        android:roundIcon="@mipmap/ic_launcher_round"
        android:supportsRtl="true"
        android:theme="@android:style/Theme.Material.Light.NoActionBar">
```

- [ ] **Step 3: Verify build**

```
./gradlew assembleDebug
```
Expected: `BUILD SUCCESSFUL`

- [ ] **Step 4: Commit**

```bash
git add app/src/main/res/xml/locale_config.xml app/src/main/AndroidManifest.xml
git commit -m "feat(i18n): add locale_config.xml for Android 13 per-app language picker"
```

```kotlin
        instructionText = instructionText,
        onImageCaptured = { bitmap ->
            instructionText = context.getString(R.string.premium_processing)
            scope.launch {
                runCatching {
                    withContext(Dispatchers.Default) {
                        extractor.extract(bitmap)
                    }
                }.onSuccess { result ->
                    instructionText = if (result.glyphs.isEmpty()) {
                        context.getString(R.string.premium_no_glyphs)
                    } else {
                        context.getString(
                            R.string.premium_capture_complete,
                            result.glyphs.size,
                            result.glyphMap.size,
                        )
                    }
                }.onFailure { throwable ->
                    instructionText = throwable.message
                        ?: context.getString(R.string.premium_capture_failed_focus)
                }
            }
        },
        onCaptureError = { throwable ->
            instructionText = throwable.message ?: context.getString(R.string.premium_camera_failed)
        },
    )
}
```
